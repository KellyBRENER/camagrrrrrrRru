=> FILTRES / IMAGES SUPERPOSABLES

- Creer un dossier pour stocker les filtres PNG transparents, par exemple :
  camagru/src/public/images/filters/

- Ajouter plusieurs filtres de base :
  - cadres transparents
  - stickers / accessoires
  - elements decoratifs avec canal alpha

- Definir comment l'application connait la liste des filtres :
  - solution simple : tableau PHP ou fichier JSON listant les filtres disponibles
  - solution plus complete : table SQL filters avec id, name, file_path, is_active

- Afficher la liste des filtres dans la page studio, dans #filtersList.

- Permettre a l'utilisateur de selectionner un filtre.

- Afficher visuellement quel filtre est selectionne.

- Desactiver le bouton de capture / creation tant qu'aucun filtre n'est selectionne.

- Ajouter un apercu cote navigateur :
  - afficher le filtre par-dessus la webcam
  - afficher le filtre par-dessus l'image uploadee / recadree
  - garder cet apercu comme aide visuelle uniquement

- Creer une route serveur pour generer l'image finale.

- Envoyer au serveur :
  - l'image capturee ou uploadee
  - l'id ou le chemin du filtre selectionne

- Generer l'image finale cote serveur en PHP :
  - charger la photo utilisateur
  - charger le PNG transparent du filtre
  - redimensionner le filtre a la taille de la photo si necessaire
  - superposer le filtre sur la photo avec imagecopy / imagecopyresampled
  - sauvegarder l'image finale

- Refuser cote serveur les filtres inconnus ou les chemins envoyes directement par l'utilisateur.

- Verifier que seuls les formats autorises sont acceptes :
  - PNG transparent pour les filtres
  - image utilisateur valide pour la photo de base

- Ajouter une table SQL pour les images creees :
  - id
  - user_id
  - image_path
  - filter_id ou filter_name
  - created_at

- Afficher les miniatures des anciennes creations de l'utilisateur dans la colonne "Mes creations".

- Permettre a l'utilisateur de supprimer uniquement ses propres images.

- Afficher les images finales dans la galerie publique, triees par date de creation.

- Bonus :
  - permettre de deplacer / redimensionner le filtre avant validation
  - permettre a l'utilisateur de creer ou uploader son propre filtre PNG
  - ajouter un apercu live du filtre directement sur la webcam
